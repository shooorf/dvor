# Лесная Цитадель — Сетевая 3D-Песочница (Godot 4.7 Forward+)

Сетевая 3D-песочница от 3-го лица для игры с друзьями под современные ПК (пресет **Ultra** рассчитан на **RTX 4070**: реальное глобальное освещение **SDFGI**, **4K HDRI-небо**, **4K PBR фотосканы**, объёмный туман, SSR-отражения, SSAO/SSIL и цветокоррекция AgX).

## Что реализовано в Baseline-версии
- **Мультиплеер (ENet UDP Listen-Server, до 16 игроков)** + режим мгновенной одиночной песочницы без настройки сети.
- **3 класса персонажей (76 боевых анимаций в каждом)**: Рыцарь в латах, Северный варвар, Разбойник в капюшоне + выбор цвета плаща и ника.
- **Полная боевая система**:
  - **Рукопашный бой**: быстрые комбо кулаками (`ЛКМ`) и тяжёлый хук (`СКМ` / `R`).
  - **Холодное оружие (1H и 2H)**: одноручный меч, фотосканированная средневековая булава, тяжёлая дубина, боевой топор, двуручный клеймор (с вихревым ударом на 360°) и фотосканированный двуручный боевой молот.
  - **Спартанский пинок (`F`) + удар о стену (Wall-Splat)**: пинок пробивает вражеский блок и с огромным физическим импульсом отшвыривает противников и бочки — при впечатывании врага на скорости в крепостную стену или заросли наносится дополнительный оглушающий урон!
  - **Блок и идеальное парирование (`ПКМ`)**: удержание щита/блока снижает урон на 82%, а нажатие за `0.25 сек` до удара полностью отражает урон со снопом искр (`ПАРИРОВАНИЕ!`).
  - **Захват и метание предметов и оружия (`E` / `G`)**: любое оружие в руках можно метнуть во врага клавишей `G` (вращающийся физический снаряд!), а ящики, дубовые бочки, **взрывные пороховые бочки**, каменные валуны и сундуки можно схватить клавишей `E` и швырнуть (`ЛКМ` или `G`).
- **Стартовая арена «Лесная цитадель» (без обрывов и пустот по краям)**: полностью замкнутый двухуровневый каменный двор крепости с запертыми дубовыми воротами и зубчатыми куртинами (Юг, Запад, Восток), переходящий на Севере в лесную поляну с древним алтарём, герметично окружённую **непролазными лесными зарослями, валунами и вековыми деревьями**. В центре двора горит огненная жаровня (поджигает тех, кого пнули в огонь), расставлены пружинные трамплины, сундук с лутом и тренировочные манекены.
- **Внутриигровое меню Песочницы (`Q`) — 17 объектов**: позволяет прямо во время сетевого матча спавнить перед собой любое оружие, обычные и пороховые бочки, валуны, рампы, трамплины, фонари, живую изгородь (**непролазные заросли**) и тренировочных манекенов.

## 1. Что установить на ПК с RTX 4070 (чистая Windows 11)

Откройте терминал **PowerShell** и поставьте только **Git** и **Python** (если ещё не установлены):

```powershell
winget install --id Git.Git -e
winget install --id Python.Python.3.13 -e
```

> **После установки перезапустите окно терминала**, чтобы команды `git` и `python` появились в `PATH`.
> Сам движок **Godot 4.7.2**, шаблоны компиляции `.exe` и все **4K PBR/HDRI/3D-ассеты** (Poly Haven, KayKit, Quaternius — 100% бесплатная лицензия CC0) скачаются автоматически нашими скриптами!

Для игры с друзьями через интернет (без проброса портов на роутере) установите любую бесплатную виртуальную локальную сеть (ставят все участники):
- **Radmin VPN** (https://www.radmin-vpn.com/ru/) **или** **Tailscale** (https://tailscale.com/).

## 2. Быстрый старт и сборка `.exe` на ПК с RTX 4070

Склонируйте ваш GitHub-репозиторий в любую папку на мощном ПК и выполните:

### Шаг 1. Автоустановка движка и 4K-ассетов (~450 МБ)
Дважды кликните по файлу **`setup.bat`** (или выполните в терминале):
```powershell
.\setup.bat
```
Скрипт сам скачает портативный Godot 4.7.2 в `.engine/`, загрузит 4K HDRI-небо, 4K PBR-текстуры и 3D-модели в `assets/downloaded/` и импортирует их.

### Шаг 2. Запуск игры из исходников
Дважды кликните по **`run.bat`**:
```powershell
.\run.bat
```
*(Если захотите покрутить сцену или подвигать объекты мышкой в визуальном редакторе Godot — запустите **`editor.bat`**).*

### Шаг 3. Сборка готового `ArenaSandbox.exe` + `.zip` архива для друзей
Дважды кликните по **`build.bat`**:
```powershell
.\build.bat
```
Скрипт автоматически докачает шаблоны компиляции под Windows x64 и соберёт:
- `dist\ArenaSandbox\ArenaSandbox.exe` — готовая игра;
- **`dist\ArenaSandbox_Win64.zip`** — готовый архив, который вы просто скидываете друзьям! Друзьям **не нужны** ни Python, ни Git, ни Godot — они просто распаковывают архив и запускают `ArenaSandbox.exe`.

## 3. Как играть по сети с друзьями

1. Все друзья подключаются к одной комнате в **Radmin VPN** (или сети **Tailscale**), либо находятся в одной домашней Wi-Fi/LAN сети.
2. **Хост** запускает игру, вводит свой ник, выбирает класс/цвет и нажимает **«★ Создать сервер для друзей (Host)»** (стандартный UDP-порт `7777`; при запросе брандмауэра Windows нажмите *«Разрешить доступ»*).
   - Прямо в главном меню и по нажатию **`Tab`** в игре Хост видит свои локальные/VPN IP-адреса.
3. **Друзья** вводят IP-адрес Хоста (например, `26.x.x.x` из Radmin VPN) в поле IP и нажимают **«⚡ Подключиться к серверу (Join)»**.

> **Совет для быстрой проверки на одном ПК:** на вашей машине с RTX 4070 можно дважды запустить `run.bat` (откроются два окна игры): в первом нажать **Host**, а во втором оставить `127.0.0.1` и нажать **Join**!

## 4. Управление в бою

| Клавиша | Действие |
| :--- | :--- |
| `W` `A` `S` `D` | Передвижение (работает на любой раскладке RU/EN) |
| `Shift` | Спринт |
| `Пробел` | Прыжок |
| `Alt` или `C` | Перекат / Рывок в сторону движения (с неуязвимостью) |
| `ЛКМ` | Комбо-удары (кулаками или оружием) / Бросок схваченного предмета |
| `СКМ` или `R` | Тяжёлый силовой удар с повышенным уроном и отбрасыванием |
| `F` | **Спартанский пинок** (пробивает блок врага и далеко отшвыривает цели и бочки!) |
| `ПКМ` *(удерж.)* | **Блок щитом/оружием** + приближение прицела (нажатие за 0.25с до удара — **Парирование**) |
| `E` | Подобрать оружие с земли **или** схватить бочку / ящик / валун / сундук |
| `G` | **Метнуть** экипированное оружие или схваченный предмет по прицелу |
| `Q` | Открыть / закрыть **Каталог спавна Песочницы** |
| `Tab` *(удерж.)* | Таблица счёта, пинга и IP сервера |
| `Esc` | Меню паузы, переключение пресета графики и чувствительности мыши |

## 5. Структура проекта и расширение контентом

```text
game1/
├── project.godot                 # Конфигурация Godot 4.7 (Forward+, 8K тени, физика, управление)
├── export_presets.cfg            # Настройки экспорта в Windows x64 .exe
├── setup.bat / setup.ps1         # Автоустановка портативного движка и 4K CC0-ассетов
├── run.bat / editor.bat          # Запуск игры или визуального редактора Godot
├── build.bat / build.ps1         # Компиляция в dist/ArenaSandbox_Win64.zip
├── scripts/
│   └── fetch_assets.py           # Мультипоточный загрузчик ассетов Poly Haven / KayKit / Quaternius
└── src/
    ├── autoload/
    │   ├── asset_catalog.gd      # Реестр оружия (WEAPON_DEFS), объектов песочницы (SANDBOX_ITEMS) и 4K PBR
    │   ├── network_manager.gd    # Сетевое ядро ENet UDP, синхронизация игроков, фрагов и событий
    │   ├── graphics_settings.gd  # Графические пресеты (Ultra RTX 4070 / High / Medium)
    │   └── sfx_manager.gd        # Процедурный 3D-синтезатор звуков ударов, звона стали и взрывов
    ├── player/
    │   └── player_character.gd   # Контроллер от 3-го лица, сетевые RPC, комбо, пинок, блок и метание
    ├── items/
    │   ├── world_weapon.gd       # Физика лежащего и летящего метательного оружия
    │   ├── physics_prop.gd       # Ящики, взрывные бочки, валуны, трамплины, рампы, заросли, жаровни
    │   └── practice_dummy.gd     # Боевой манекен с HP, ударом о стену и автореспавном
    ├── world/
    │   ├── arena_level.gd        # Генерация и логика замкнутой арены «Лесная цитадель»
    │   └── vfx_helper.gd         # Частицы искр, щепок, взрывов, огня и всплывающий урон
    └── ui/
        ├── main_menu.gd          # Главное меню с живой 3D-диорамой бойца
        └── game_hud.gd           # Боевой HUD, меню Песочницы [Q], счёт [Tab] и пауза [Esc]
```

### Как легко добавлять новые объекты потом
Все оружия и предметы песочницы сведены в единый реестр `src/autoload/asset_catalog.gd`:
1. Положите любую бесплатную `.glb` / `.gltf` модель в папку `assets/` (или добавьте её ID из Poly Haven в `scripts/fetch_assets.py`).
2. Добавьте запись в `WEAPON_DEFS` (для нового оружия) или в `SANDBOX_ITEMS` + `src/items/physics_prop.gd` (для нового интерактивного объекта). Он автоматически появится в сетевом меню **`[Q]`** у всех игроков!
